# Used Car Digital Growth Ecosystem — MVP

A demo dealership operating system based on the VandLabs Used-Car Digital Growth Ecosystem specification.

## MVP
- Public dealership storefront
- Inventory browsing + vehicle detail pages
- Vehicle enquiry / callback flow
- Dealer dashboard
- Inventory management view
- Lead pipeline: New → Contacted → Qualified → Appointment → Won
- Appointment management
- Acquisition / vehicle analytics
- Dealership settings
- Placeholder WhatsApp integration
- Placeholder lead API
- Mock inventory and lead data

## Run
```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production integrations to add later
- Supabase/Postgres persistence
- Authentication + role-based access
- WhatsApp Business provider
